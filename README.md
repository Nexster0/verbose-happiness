# Chemistry olympiad tasks (Kazakhstan)

Task PDFs only (no solutions) from https://olympiads.bc-pf.org/chemistry.

- `chemistry/republic/2020-2024/<grade>/` - republican stage
- `chemistry/oblast/2020-2024/<grade>/` - oblast stage
- `chemistry/region/2020-2024/<grade>/` - district stage
- `chemistry/kaz_sbory/<session>/` - Kazakhstan team training camps (all sessions on the site, 2016-2018)

Re-download with `python3 download.py`.
